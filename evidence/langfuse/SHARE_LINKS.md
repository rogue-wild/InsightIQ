## Project-wide public link?

**Langfuse does not support a public share link for an entire project.**  
Only **individual traces/sessions** can be shared without login. For bulk runs, commit an **export** (CSV/JSON) into this folder.

| Method | Scope | Login required? |
|--------|--------|-----------------|
| Trace / session share | One run | No (when public) |
| CSV / JSON export in repo | Many observations | No (in git) |
| Project URL (`/project/...`) | Whole project | Yes — not judge evidence alone |
