# Click-a-thon submission guide (this repo)

This repository is ready to drop into the [click-a-thon-2026 submissions](https://github.com/sidagarwal04/click-a-thon-2026) fork as:

```
<YourTeamName>/
  ├── (all InsightIQ source — copy or submodule)
  ├── README.md              ✅ submission template
  ├── ARCHITECTURE.md        ✅
  ├── pitch-deck.pdf         ⬜ export from pitch-deck.md
  ├── demo-video link        ⬜ in README
  └── evidence/
        ├── langfuse/        ⬜ public share links + JSON
        └── unseen/          ⬜ graded export JSON after release
```

## Before opening the PR

1. Set **team folder name** = your official team name  
2. Fill **Team Members** in `README.md`  
3. Record **2–3 min demo video** → paste URL in README  
4. Export **pitch-deck.pdf** from `pitch-deck.md`  
5. Add **Langfuse public share links** in `evidence/langfuse/SHARE_LINKS.md`  
6. When unseen data drops → run export → commit under `evidence/unseen/`  
7. PR title: `[Submission] Your Team Name`  
8. Do **not** put secrets in the submission (`.env.example` only)

## PR title format

```
[Submission] Your Team Name
```
